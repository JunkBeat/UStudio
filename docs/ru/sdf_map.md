# Файл sdf_map.txt: формат и примеры

Одна строка карты соответствует настройке для одного или нескольких SDF шрифтов: **слева от знака «=»** следует писать имена SDF шрифтов через запятую; **справа** — векторный шрифт, откуда надо брать символы и, по желанию, настройки через запятую.

Быстрый пример:

```
"Arial SDF" = arial.ttf
"Pixel SDF", "Pixel SDF Bold" = pixel.ttf, mode=full, chars="АБВ"
```

#### Основные настройки mapping файла

| Имя | Значение | Предназначение |
|---|---|---|
| `mode` | `add`, `replace`, `full` | Режим генерации:<br>• **add** — добавление символов;<br>• **replace** — добавление + замена символов;<br>• **full** — полная подмена.<br><small>*(по умолчанию `add`)*</small> |
| `chars` | строка или имя текстового<br>файла с символами | Символы, участвующие в генерации |

#### Настройки, доступные только для режима `full`

| Имя | Значение | Предназначение |
|---|---|---|
| `size` | число или `fit` | Размер шрифта: любое число, или `fit`, что означает «Вписать в текстуру». |
| `range` | число | Задать значение резкости краёв.<br>• *Для пиксельных шрифтов ~4px;*<br>• *Для гладких шрифтов ~10px* |
| `match_height` | `on` или `off` | Подгонять ли высоту букв под оригинал.<br><small>*(по умолчанию `on`)*</small> |
| `add_chars` | `on` или `off` | Добавлять ли в обработку символы, которые есть в SDF шрифте, но не перечислены в `chars`.<br><small>*(по умолчанию `on`)*</small> |
| `atlas` | числа в формате<br>1024x512 | Жёстко задать размер атласа *(но обычно это не нужно)*. |

<small>*Если `size` и `range` не указаны, берутся значения из SDF.*</small>

#### Общие настройки — строка `default:`

Строка `default:` *(одна на файл, в любом месте)* задаёт настройки для тех строк, где
они не указаны. Собственная настройка строки всегда остаётся в приоритете и переопределяет её. Настройки режима `full`, перечисленные в `default` строке, применяются только к строкам, для которых итоговым режимом будет `mode=full`.
<br><br>Пример работы:

```
default: size=48, range=6

# Шрифт получает size=48 и range=6 из default
"Title SDF" = title.ttf, mode=full

# Режим add по умолчанию: size/range из default игнорируются
"Body SDF"  = body.ttf

# ОШИБКА: size несопоставим с режимом add
"Menu SDF"  = menu.ttf, mode=add, size=40
```

#### Способы указания целевого SDF

- **Имя объекта TMP_FontAsset** — генерация для всех SDF шрифтов с таким именем.
<br>*Пример: `"Arial SDF"`.*
- **Ссылка** — источник + PathID.
<br>*Пример: `level0:55`.*

#### Подробное описание `chars=`

- `chars="abc"` — перечисление символов в двойных кавычках.
- `chars=my_chars.txt` — имя текстовика с символами, без кавычек (или путь относительно mapping файла вида `chars=sub/x.txt`).
В текстовике ничего экранировать не нужно. Переводы
строк и табуляции пропускаются, повторы не страшны.
- Если настройки `chars` нет ни в локальной строке, ни в `default`, символы берутся из файла `chars.txt` в папке рядом с маппингом. Если нет и его — выдаётся ошибка.

Спецсимволы внутри `chars="..."`:

| Что пишем | Что получаем |
|---|---|
| `\"` | Двойную кавычку |
| `\\` | Обратную косую черту |
| `\uXXXX` | Символ по коду, 4 цифры (`\u00AB` — «) |
| `\UXXXXXXXX` | Символ по коду, 8 цифр (эмодзи и т. п.) |

Любая другая обратная косая черта считается за ошибку.

#### Другие примечания

- Для `sdf_map.txt` и файлов c символами требуется кодировка **UTF-8** (с BOM или без). В кодировке «ANSI» / Windows-1251 кириллица прочитается некорректно.
- Строки, которые начинаются с символа `#` — считаются комментариями и пропускаются.

### Примеры использования

*Напоминание:*

- *Если режим генерации не указан, по умолчанию используется `add`.*
- *Если настройка `chars` не указана, символы берутся из `chars.txt`.*

**1.** Добавить недостающие символы в один SDF:

```
"Arial SDF" = arial.ttf
```

**2.** Добавить недостающие символы из одного ttf во множество SDF:

```
"Arial SDF", "Arial SDF Bold", "Arial SDF Title" = arial.ttf
```

**3.** У каждого SDF шрифта свой источник, а символы и режим генерации общие:

```
default: mode=add, chars=cyrillic.txt
"Body SDF" = roboto.ttf
"Title SDF" = "fonts/Bebas Neue.ttf"
"Menu SDF" = "fonts/Open Sans, Bold.ttf"
```

**4.** Заменить SDF, вписав символы в текстуру:

```
"Pixel SDF" = pixel.ttf, mode=full, size=fit, chars=cyrillic.txt
```

**5.** Заменить SDF, задавая размер, без подгонки высоты, с мягкими краями:

```
"Main SDF" = main.ttf, mode=full, size=48, match_height=off, range=8
```

**6.** Заменить SDF в режиме add, указав ссылку на TMP_FontAsset вместо имени:

```
level0:55 = main.ttf
```

**7.** Указать кавычки и спецсимволы для генерации:

```
"Text SDF" = text.ttf, chars="«»„“”—–…\"'"
"Icons SDF" = icons.ttf, chars="\u2605\u2606\U0001F600"
```

**8.** Заглавный SDF заменить целиком, остальные генерировать в режиме add:

```
default: mode=add, chars=cyrillic.txt
"Title SDF" = title.ttf, mode=full, size=fit, range=6
"Body SDF", "Body SDF Italic" = body.ttf
```
