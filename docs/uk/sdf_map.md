# Файл sdf_map.txt: формат і приклади

Один рядок карти задає налаштування для одного або кількох SDF-шрифтів: **ліворуч від знака «=»** пишуться імена SDF-шрифтів через кому; **праворуч** — векторний шрифт, з якого брати символи, і, за бажанням, налаштування через кому.

Швидкий приклад:

```
"Arial SDF" = arial.ttf
"Pixel SDF", "Pixel SDF Bold" = pixel.ttf, mode=full, chars="АБВ"
```

#### Основні налаштування mapping-файлу

| Ім’я | Значення | Призначення |
|---|---|---|
| `mode` | `add`, `replace`, `full` | Режим створення:<br>• **add** — додавання символів;<br>• **replace** — додавання + заміна символів;<br>• **full** — повна заміна.<br><small>*(за замовчуванням `add`)*</small> |
| `chars` | рядок або ім’я текстового<br>файлу із символами | Символи, які беруть участь у створенні |

#### Налаштування лише для режиму `full`

| Ім’я | Значення | Призначення |
|---|---|---|
| `size` | число або `fit` | Розмір шрифту: будь-яке число або `fit`, тобто «Вписати в текстуру». |
| `range` | число | Різкість країв.<br>• *Для піксельних шрифтів ~4px;*<br>• *Для гладких шрифтів ~10px* |
| `match_height` | `on` або `off` | Чи підганяти висоту літер під оригінал.<br><small>*(за замовчуванням `on`)*</small> |
| `add_chars` | `on` або `off` | Чи обробляти також символи, які є в SDF-шрифті, але не перелічені в `chars`.<br><small>*(за замовчуванням `on`)*</small> |
| `atlas` | числа у форматі<br>1024x512 | Жорстко задати розмір атласу *(зазвичай це не потрібно)*. |

<small>*Якщо `size` і `range` не вказано, беруться значення з SDF.*</small>

#### Спільні налаштування — рядок `default:`

Рядок `default:` *(один на файл, у будь-якому місці)* задає налаштування для тих рядків, де
їх не вказано. Власне налаштування рядка завжди має пріоритет над ним. Налаштування режиму `full`, перелічені в рядку `default`, застосовуються лише до рядків, для яких підсумковим режимом буде `mode=full`.
<br><br>Як це працює:

```
default: size=48, range=6

# Шрифт отримує size=48 і range=6 з default
"Title SDF" = title.ttf, mode=full

# Режим add за замовчуванням: size/range з default ігноруються
"Body SDF"  = body.ttf

# ПОМИЛКА: size несумісний із режимом add
"Menu SDF"  = menu.ttf, mode=add, size=40
```

#### Як указати цільовий SDF

- **Ім’я об’єкта TMP_FontAsset** — створення для всіх SDF-шрифтів із таким іменем.
<br>*Приклад: `"Arial SDF"`.*
- **Посилання** — джерело + PathID.
<br>*Приклад: `level0:55`.*

#### Докладніше про `chars=`

- `chars="abc"` — символи в подвійних лапках.
- `chars=my_chars.txt` — ім’я текстового файлу із символами, без лапок (або шлях відносно mapping-файлу, як-от `chars=sub/x.txt`).
У текстовому файлі нічого екранувати не потрібно. Переноси
рядків і табуляції пропускаються, повтори не страшні.
- Якщо `chars` не задано ні в рядку, ні в `default`, символи беруться з файлу `chars.txt` у теці поруч із mapping-файлом. Якщо немає і його — це помилка.

Спецсимволи всередині `chars="..."`:

| Що пишемо | Що отримуємо |
|---|---|
| `\"` | Подвійну лапку |
| `\\` | Зворотну косу риску |
| `\uXXXX` | Символ за кодом, 4 цифри (`\u00AB` — «) |
| `\UXXXXXXXX` | Символ за кодом, 8 цифр (емодзі тощо) |

Будь-яка інша зворотна коса риска вважається помилкою.

#### Інші примітки

- `sdf_map.txt` і файли із символами мають бути в кодуванні **UTF-8** (з BOM або без). У кодуванні «ANSI» / Windows-1251 кирилиця прочитається неправильно.
- Рядки, що починаються із символу `#`, — коментарі й пропускаються.

### Приклади

*Нагадування:*

- *Якщо режим створення не вказано, використовується `add`.*
- *Якщо `chars` не вказано, символи беруться з `chars.txt`.*

**1.** Додати відсутні символи в один SDF:

```
"Arial SDF" = arial.ttf
```

**2.** Додати відсутні символи з одного ttf у багато SDF:

```
"Arial SDF", "Arial SDF Bold", "Arial SDF Title" = arial.ttf
```

**3.** У кожного SDF-шрифту своє джерело, а символи й режим спільні:

```
default: mode=add, chars=cyrillic.txt
"Body SDF" = roboto.ttf
"Title SDF" = "fonts/Bebas Neue.ttf"
"Menu SDF" = "fonts/Open Sans, Bold.ttf"
```

**4.** Замінити SDF, вписавши символи в текстуру:

```
"Pixel SDF" = pixel.ttf, mode=full, size=fit, chars=cyrillic.txt
```

**5.** Замінити SDF із заданим розміром, без підгонки висоти, з м’якими краями:

```
"Main SDF" = main.ttf, mode=full, size=48, match_height=off, range=8
```

**6.** Створити в режимі add, указавши посилання на TMP_FontAsset замість імені:

```
level0:55 = main.ttf
```

**7.** Лапки й спецсимволи для створення:

```
"Text SDF" = text.ttf, chars="«»„“”—–…\"'"
"Icons SDF" = icons.ttf, chars="\u2605\u2606\U0001F600"
```

**8.** Заголовний SDF замінити цілком, решту створити в режимі add:

```
default: mode=add, chars=cyrillic.txt
"Title SDF" = title.ttf, mode=full, size=fit, range=6
"Body SDF", "Body SDF Italic" = body.ttf
```
